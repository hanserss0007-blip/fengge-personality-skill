# OCEAN 大五人格 — 直播场景行为映射表

## 使用说明

本表将 OCEAN 大五人格每个维度映射到直播/视频中可观察的具体行为。
LLM 分析时根据行为频率和强度进行 1-5 评分，每个评分必须有具体视频时间戳证据。

## O — Openness 开放性（对新经验的接纳程度）

| 高分行为 | 低分行为 |
|---------|---------|
| 主动探索危险/未知地点（缅甸、乌克兰） | 回避陌生话题 |
| 对不同观点持好奇态度，追问而非驳回 | 观点固化，拒绝新信息 |
| 内容类型多样，不重复同一模式 | 内容高度重复 |
| 讨论抽象概念、哲学问题 | 只谈具体、实用话题 |
| 尝试不同的直播形式/内容方向 | 形式固化 |

## C — Conscientiousness 尽责性（组织、自律、目标导向）

| 高分行为 | 低分行为 |
|---------|---------|
| 直播有备稿/准备框架 | 随性开播，无准备 |
| 持续产出，有规律更新 | 三天打鱼两天晒网 |
| 对承诺负责（答应了就连线到底） | 随意下播、跳票 |
| 内容有结构和层次 | 想到哪说到哪 |
| "自媒体就是为了逃避劳动" — 自我描述 | 对工作结果有高标准 |

## E — Extraversion 外向性（社交能量、积极性）

| 高分行为 | 低分行为 |
|---------|---------|
| 长时间直播不疲惫 | 直播中明显疲劳/不想说话 |
| 主动引导对话，控制节奏 | 被动回应 |
| 在陌生环境快速社交（街头搭讪、拉人入镜） | 回避社交 |
| 高能量、语速快、音量高 | 低能量、沉默寡言 |
| 享受成为焦点 | 不自在被关注 |

## A — Agreeableness 宜人性（合作、共情、信任）

| 高分行为 | 低分行为 |
|---------|---------|
| 对底层群体表现真诚共情 | 对弱者冷漠/嘲讽 |
| 连麦时耐心倾听，不随意打断 | 频繁打断、贬低对方 |
| 被批评时理性回应 | 被批评时攻击/拉黑 |
| 承认自己错误 | 从不认错，转移话题 |
| 帮助求助者 | 利用求助者制造节目效果 |

## N — Neuroticism 神经质（情绪稳定性）

| 高分行为 | 低分行为 |
|---------|---------|
| 情绪波动大，容易被激怒 | 面对挑衅保持冷静 |
| 对负面评论反应过度 | 对批评一笑而过 |
| 焦虑/不安（被封禁后的反应等） | 疫情绪稳定 |
| 内容情绪化（大喜大悲） | 情绪基调平稳 |
| 事后反复提及/纠结同一件事 | 事件过后不再纠结 |

## 评分标准

| 分数 | 含义 | 要求 |
|------|------|------|
| 1 | 极低 | 几乎从不表现该特质高分行为，频繁表现低分行为 |
| 2 | 偏低 | 偶尔表现高分行为，经常表现低分行为 |
| 3 | 中等 | 高分和低分行为各半，或情境依赖性很强 |
| 4 | 偏高 | 经常表现高分行为，偶尔表现低分行为 |
| 5 | 极高 | 几乎总是表现高分行为，几乎不表现低分行为 |

## 证据链格式

每条评分需要 3+ 条证据：

```json
{
  "trait": "Openness",
  "score": 4,
  "evidence": [
    {
      "video_id": "BVxxxxxx",
      "timestamp": "01:23:45",
      "behavior": "主动前往缅甸妙瓦底拍摄",
      "trait_indicator": "主动探索危险未知地点（高开放性）"
    }
  ]
}
```

## 注意

- OCEAN 是连续谱，不是非此即彼
- 同一人在不同场景可能表现不同分数，需标注情境
- 直播人格 ≠ 私下人格，评分反映的是公开呈现的人格
- 峰哥的「抽象」风格可能系统性地压低 A（宜人性）评分，需区分表演和真实
