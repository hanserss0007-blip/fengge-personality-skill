# 五维度人格分析框架

## 总览

本框架将人格分析分解为五个独立但互补的维度，每维度有明确的操作化指标和分析方法。

## 维度 1：语言风格

### 分析目标
刻画峰哥的语言指纹 — 他独特的表达方式和语言习惯。

### 操作化指标

| 指标 | 方法 | 数据 |
|------|------|------|
| 高频词汇 | jieba 分词 + 词频统计 | 峰哥独白 |
| 口头禅 | n-gram (2-5) + TF-IDF 显著性 | 峰哥独白 |
| 句长分布 | 中位句长、句长方差 | 峰哥独白 |
| 句式偏好 | 陈述/疑问/祈使/感叹比例 | 峰哥独白 |
| 修辞手段 | LLM标注：比喻/反讽/夸张/排比频率 | 抽样50段 |
| 语气强度 | 感叹词频率、粗话比例、程度副词 | 全量语料 |

### 输出
`outputs/language_analysis.json` — 口头禅Top20、词云数据、句式分类统计

## 维度 2：思维模式

### 分析目标
分析峰哥的论证结构、推理方式和认知倾向。

### 操作化指标

| 指标 | 方法 | 数据 |
|------|------|------|
| 论证结构 | LLM标注：主张-证据-结论链 | 抽样50段论证 |
| 逻辑谬误 | LLM标注：人身攻击/稻草人/假二分/滑坡等 | 抽样50段论证 |
| 认知偏差 | LLM标注：确认偏误/锚定/可得性启发等 | 抽样50段论证 |
| 抽象 vs 具体 | 抽象名词比例 vs 具体事例比例 | 全量语料 |
| 确定性语言 | "一定/绝对/肯定" vs "可能/也许/大概" 比例 | 全量语料 |

### 输出
`outputs/thinking_analysis.json` — 论证结构分类、逻辑谬误频次、认知偏差分布

## 维度 3：价值体系

### 分析目标
识别峰哥的核心价值观和立场一致性。

### 操作化指标

| 指标 | 方法 | 数据 |
|------|------|------|
| 主题分布 | BERTopic 主题建模 + LLM 标签 | 全量语料 |
| 价值维度 | LLM 评分：政治/经济/社会公正/权威态度/性别观 | 按主题聚类 |
| 立场一致性 | 跨时间/跨语境立场对比 | 时间序列 |
| 核心价值观 | LLM提取反复出现的价值陈述 | 全量语料 |

### 价值评分维度（LLM 7点量表）
1. 权威 vs 自由
2. 传统 vs 进步
3. 个人主义 vs 集体主义
4. 犬儒主义 vs 理想主义
5. 物质主义 vs 精神追求

### 输出
`outputs/values_analysis.json` — 主题聚类、价值维度雷达图数据、立场一致性分数

## 维度 4：人际互动

### 分析目标
分析峰哥在不同社交场景中的互动模式。

### 场景分类

| 场景 | 互动对象 | 分析重点 |
|------|---------|---------|
| 连麦-普通观众 | 陌生人 | 权力距离、耐心程度、敷衍 vs 认真 |
| 连麦-熟人/嘉宾 | 同行 | 合作 vs 竞争、尊重 vs 调侃 |
| 弹幕互动 | 匿名观众 | 对批评的回应、幽默化解、冲突处理 |
| 独白输出 | 镜头（观众） | 说服策略、自我呈现、情绪感染 |

### 操作化指标

| 指标 | 方法 |
|------|------|
| 打断频率 | 连麦对话中打断对方的次数（LLM标注） |
| 共情语句比例 | "我理解" / "你说的对" / 复述对方观点 |
| 冲突升级 vs 化解 | 面对挑衅时的回应策略分类 |
| 幽默使用 | 自嘲 vs 嘲讽他人的比例 |
| 互动时间分配 | 自己说话 vs 让对方说话的时间比 |

### 弹幕-视频时间对齐分析
- 高密度弹幕时刻（爆点）前后的语言特征
- 引起弹幕共鸣/争议的话语类型

### 输出
`outputs/interaction_analysis.json` — 场景互动模式、冲突处理策略、弹幕响应分析
