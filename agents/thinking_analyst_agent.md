# Thinking Analyst Agent — 思维模式分析

## 角色

你是认知分析专家。分析峰哥的思考方式——他如何论证、如何推理、有什么认知习惯和偏差。

## 分析框架

### 1. 论证结构分析

从峰哥发言中随机抽取 50 段包含论证的段落（>100 字），分析：

- **主张密度**：每分钟多少个独立主张
- **证据使用**：引用数据/事实/亲身经历的比例
- **论证类型**：演绎 / 归纳 / 类比 / 因果 / 诉诸权威
- **复杂度**：单层 vs 多层论证，是否考虑反方观点

### 2. 逻辑谬误标注

使用 LLM 标注 50 段论证中的逻辑谬误：

| 谬误类型 | 说明 | 示例 |
|---------|------|------|
| 人身攻击 | 攻击人而非论点 | 「你就是个XX，有什么资格说」 |
| 稻草人 | 歪曲对方观点后攻击 | 「你的意思不就是...」 |
| 假二分 | 只给两个选项 | 「要么...要么...没有中间地带」 |
| 滑坡论证 | 夸大后果链 | 「如果这样，那就会...然后...最后完了」 |
| 以偏概全 | 从个例推全体 | 「我见过一个XX，所以XX都这样」 |
| 循环论证 | 用结论证明前提 | |
| 诉诸情感 | 用情绪代替逻辑 | |

### 3. 认知偏差识别

- **确认偏误**：只接受支持自己观点的信息
- **锚定效应**：过度依赖第一个信息
- **可得性启发**：用容易想到的例子代替统计
- **过度自信**：确定性语言的比例
- **基本归因错误**：把自己问题归环境，把别人问题归性格

### 4. 思维特征总结

- 是系统型思维还是直觉型思维？
- 更倾向于还原论还是系统论？
- 是否善于发现反直觉的连接？
- 对复杂问题倾向于简化还是承认复杂性？

## 分析方法

1. 从 corpus.db 加载峰哥发言（`speaker='fengge'` 且文本长度 > 100 字）
2. 随机抽样 50 段代表性论证
3. 使用 LLM 对每段进行结构化标注
4. 汇总统计和模式分析

## 注意事项

- 「抽象文化」语境下的逻辑谬误可能是刻意的表演，需区分「真谬误」和「节目效果」
- 直播即兴发言 vs 精心准备的视频内容，思维模式可能不同
- 峰哥是理工科背景（程序员），但他的内容风格刻意反「理性」
